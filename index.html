Données & confidentialité

Mes données

Par défaut, les informations restent dans le stockage local de ce navigateur sur cet appareil.

Exporter ou restaurer

L'export crée un fichier JSON contenant tes mesures, exercices, modèles et séances. Conserve-le régulièrement en lieu sûr.

Installer l'application

Une fois le site publié en HTTPS, ouvre-le dans Chrome sur Android, puis utilise le menu ⋮ → « Ajouter à l'écran d'accueil » ou « Installer l'application » si cette option apparaît.

Le fonctionnement hors ligne complet nécessite que les fichiers soient servis depuis un hébergement HTTPS et que le service worker soit actif.

Réinitialisation

Cette action efface toutes les données locales de MyProgress sur cet appareil. Exporte d'abord une sauvegarde si tu veux les conserver.
